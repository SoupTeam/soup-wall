This is per-file guarded publication, not global multi-rename atomicity. Explicit
sole-writer maintenance is a prerequisite, including arbitrary same-UID writers.

recoverable; visible receipts or matching bytes do not manufacture completion.

write authority is introduced. Original outputs and recovery records remain.
The accepted 4096-byte replacement, 8-member, 9-file / 144 KiB staging and existing
resource/time limits stay unchanged. Live quotas and export/diff/archive formats
are unchanged. A pre-rename kill can retain native named staging evidence; the
workflow preserves it and refuses unsafe publication instead of deleting by name.
