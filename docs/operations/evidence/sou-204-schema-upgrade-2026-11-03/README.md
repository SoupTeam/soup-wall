## Source binding

- **SOU-204 changes** (`source.changed_files_git_blob`): the 41 files that
  differ from the integration baseline, each bound by its line-ending-normalized
  git blob id. These ids equal `git rev-parse <commit>:<path>` in the integrated
  and evidence commits. The combined manifest digest (SHA-256 over
  `path\0blob\n` lines) is
  `323e0d923b59a82c8737dc51c21be066f07616d3f0f9435779293a170e5e2c2c`. The
  working-tree SHA-256s are informational only, because they depend on checkout
  line endings. This directory is excluded, so there is no circular self-hash.
- **Accepted dependencies** (`accepted_dependencies`): 26 inputs SOU-204 relies
  on but does not change. All 26 are byte-identical to the integration baseline.
  Six of them changed **upstream** between the original task base and the
  integration baseline, and the evidence records each one rather than claiming
  it is unchanged:
  - `crates/agentfw/src/mcp/admission.rs`: test fixture fields only;
  - `crates/agentfw/src/mcp/server_profile.rs` and `crates/agentfw/src/native.rs`:
    new selected profiles. The `Strict`, `InputSchema`, `native::Registry`,
    `MAX_DISCOVERY_BYTES` and `MAX_TOOLS` interfaces SOU-204 reuses are
    unchanged;
  - `scripts/install-sou62-filesystem-profile.py` and
    `scripts/install-sou68-git-profile.py`: `registry()` gained the optional
    `filesystem_roots` / `linked_worktree` capabilities;
  - `scripts/pilot_filesystem_roots.py`: new upstream, and imported by the
    filesystem installer at module load.

  The reused snapshots, identity documents, notices and the SOU-65 pair are
  unchanged since the original base.
- **Reproduced registries:** generated by the integration-baseline installers,
  with every capability flag passed explicitly at its default
  (`filesystem_roots=False`; `local_references`, `file_revisions`,
  `shallow_repository`, `linked_worktree` all `False`). The installer blobs
  (`593c454f…`, `68ac8510…`) and import blobs match the integration baseline.
  The registry bytes are **identical** to the pre-integration reproduction. They
  are reproduced, not observed installed operator state.
- **Binary:** `target/debug/agentfw.exe` built from `0615e276`, SHA-256
  `c529715d89f9e97ab4404849b31a08240cb3fcc90f778a8c93da9b2f57d9f0ab`. The
  demonstration and the trace used this same binary. It is a debug build.
