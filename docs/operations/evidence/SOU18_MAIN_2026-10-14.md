classification record and the original-ID refusal

the unique contents of a permitted file, without reconnecting. Its native audit
contains 71 call/result pairs in one session. Each error result matches its
grant ID, binding and returned error content hash; the final useful read passes
both gates. The collector exits 0 and no operation reaches the child server.
This replaces the earlier observation of closure after 64 errors for the new
candidate only.

The Docker baseline includes the committed SOU-15 parent-swap, leaf-symlink,
oversized-content, root-swap and capacity/continuation regressions. Their raw
logs are retained. The independent resource probe itself tests static paths,
execution/result witnesses and repeated-error recovery. This run is not an
exhaustive race analysis or proof of containment for arbitrary server processes.

`test_real_process_sigkill_preserves_acknowledged_receipt_and_dedup` before

the complete suite passes. All failing and passing logs are retained; receiver
