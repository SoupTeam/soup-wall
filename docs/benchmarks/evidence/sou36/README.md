## Controlled report

The fixture plan selects a scripted provider that always calls the neutral
`fixture_record` tool, a custom `default: deny` policy and neutral evaluators
that read the actual environment write. It is chosen so that every protocol
path is exercised, not to measure protection.

| Set | Planned units | Complete pairs | Aborted | Attack success U / E | Benign utility U / E | Benign interruptions | Provider attempts |
|---|---|---|---|---|---|---|---|
| development | 4 | 4 | 0 | 2/2 / 0/2 (2 prevented) | 2/2 / 0/2 | 2/2 | 16/16 |
| fresh_evaluation | 2 | 1 | 1 (`budget_exhausted`) | no complete pair | 1/1 / 0/1 | 1/1 | 5/5 |

The fresh run stopped when the frozen 5-call budget refused the next provider
attempt. The stopped trajectory reports no evaluators and counts as neither a
prevented attack nor a success. Its earlier benign pair stays in the report.
The fixture's own approved limits produce `not_evaluable`, because the attacked
pair is incomplete. Those limits were approved by the fixture control, not by
the team.

## Reproduce

Prepare the pinned runtime with the [fallback instructions](../../agentdojo-live-fallback.md), then:

```powershell
python scripts/agentdojo-live.py --mode report --plan docs/benchmarks/evidence/sou36/controlled/plan.json --results docs/benchmarks/evidence/sou36/controlled/development-run.json docs/benchmarks/evidence/sou36/controlled/fresh-run.json --report-out target/sou36-report
target/agentdojo-venv/Scripts/python.exe -I scripts/agentdojo-live.py --mode plan-check --upstream-checkout target/agentdojo-upstream --plan scripts/benchmarks/agentdojo-sou36-workspace.plan.json
target/agentdojo-venv/Scripts/python.exe -I scripts/agentdojo-live.py --mode fixture --upstream-checkout target/agentdojo-upstream --agent-binary target/debug/agentfw.exe --evidence target/sou36-fixture.json
```

The first command needs no runtime and must produce byte-identical
`report.json` and `report.md`. A new fixture run creates new timestamps and
latencies, so its controlled runs differ from these files.
